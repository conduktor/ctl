# APT Publishing Design for conduktor-ctl

**Date:** 2026-10-21
**Author:** Ben
**Status:** Approved

---

## Overview

Add apt repository support so users can install `conduktor-ctl` via `apt-get`. A shared `conduktor/apt` repository hosts the apt index via GitHub Pages, following the same pattern as `conduktor/homebrew-brew`. The `conduktor/ctl` release workflow builds `.deb` packages using `nfpm` and publishes them into `conduktor/apt`.

---

## User-Facing Install Flow

```bash
curl -fsSL https://conduktor.github.io/apt/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/conduktor.gpg
echo "deb [signed-by=/etc/apt/keyrings/conduktor.gpg] https://conduktor.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/conduktor.list
sudo apt update
sudo apt install conduktor-ctl
```

The apt repo URL is `https://conduktor.github.io/apt`, served from the `main` branch of the new `conduktor/apt` GitHub repository via GitHub Pages. The single distribution is `stable`.

---

## Components

### 1. New repo: `conduktor/apt`

A shared apt repository for all current and future Conduktor tools.

**Structure:**
```
conduktor/apt/
├── conf/
│   └── distributions          # reprepro config: stable/main
├── gpg.key                    # exported public GPG key (for users to import)
├── dists/                     # generated by reprepro (committed)
├── pool/                      # generated by reprepro (committed)
└── README.md                  # user install instructions
```

**GitHub Pages:** enabled on `main` branch, root directory. Serves the apt index at `https://conduktor.github.io/apt`.

**`conf/distributions`:**
```
Origin: Conduktor
Label: Conduktor
Codename: stable
Architectures: amd64 arm64
Components: main
Description: Conduktor apt repository
SignWith: <GPG key ID>
```

### 2. `nfpm.yaml` (added to `conduktor/ctl`)

Describes the `.deb` package metadata:

```yaml
name: conduktor-ctl
arch: "${GOARCH}"
platform: linux
version: "${VERSION}"
maintainer: Conduktor <support@conduktor.io>
description: Conduktor command line tools
homepage: https://conduktor.io
license: Apache-2.0
contents:
  - src: ./conduktor
    dst: /usr/local/bin/conduktor
```

Architecture and version are injected via environment variables at build time.

### 3. `publish-apt` job (added to `conduktor/ctl` release workflow)

Runs after `build-exec` completes (Linux binaries must exist as release assets).

**Steps:**
1. Download `conduktor-linux-amd64.tar.gz` and `conduktor-linux-arm64.tar.gz` from the GitHub Release
2. Extract binaries
3. Run `nfpm pkg` for each architecture to produce `.deb` files
4. Import GPG private key from secrets
5. Check out `conduktor/apt` repo
6. Run `reprepro includedeb stable <package>.deb` for each `.deb`
7. Commit and push directly to `main` of `conduktor/apt`

**Secrets required in `conduktor/ctl`:**
- `CONDUKTORBOT_REPO_WRITE` — already exists, used by the `bump` job
- `GPG_PRIVATE_KEY` — new, the armored private key (no passphrase)

## One-Time Setup: GPG Key

A new GPG key must be generated and configured before the workflow runs. This is a manual step performed once.

**Generate:**
```bash
gpg --batch --gen-key <<EOF
%no-protection
Key-Type: RSA
Key-Length: 4096
Subkey-Type: RSA
Subkey-Length: 4096
Name-Real: Conduktor
Name-Email: support@conduktor.io
Expire-Date: 0
EOF
```

**Export public key** → commit to `conduktor/apt` as `gpg.key`:
```bash
gpg --armor --export support@conduktor.io > gpg.key
```

**Export private key** → store as `GPG_PRIVATE_KEY` secret:
```bash
gpg --armor --export-secret-keys support@conduktor.io
```

**Secrets needed in `conduktor/ctl`:**
- `GPG_PRIVATE_KEY` — the exported private key (no passphrase with `%no-protection`)

## Publishing Flow Diagram

```
conduktor/ctl release tag published
        │
        ├── unit-test ──────────────────────────────────────────┐
        ├── integration-test ────────────────────────────────────┤
        │                                                        │
        │   (existing)                            (existing)     │
        ├── build-exec ──► GitHub Release assets  bump ──► homebrew-brew
        │       │
        │       ▼  (new)
        └── publish-apt
                │
                ├── download linux amd64/arm64 binaries
                ├── nfpm → .deb (amd64 + arm64)
                ├── checkout conduktor/apt
                ├── reprepro includedeb stable *.deb
                └── git push → conduktor/apt main
                                    │
                                    └── GitHub Pages
                                        https://conduktor.github.io/apt
```

## Scope

**In scope:**
- `conduktor/apt` repo creation and GitHub Pages setup
- `nfpm.yaml` added to `conduktor/ctl`
- `publish-apt` job added to `conduktor/ctl` release workflow
- One-time GPG key generation (manual step, documented)
- `README.md` in `conduktor/apt` with user install instructions

**Out of scope:**
- RPM/yum support
- Multiple distributions (focal, jammy, etc.) — single `stable` only
- Migrating existing `build-exec` to GoReleaser
- Any other Conduktor tools (they follow the same pattern when ready)
